## The order we test in

Lifecycle first, in the order a real person meets it. Not footer links, not
trivia. The client's rule: *"the life cycle is the priority, not the buttons
which do minor stuff."*

1. Student, direct from an advert: land, sign in, sit the ten, hit the gate
2. Student, state: answer one, leave, come back, back button
3. Student, pay: pricing, checkout, QR, submit, wait, rejected, retry
4. Super admin: approve, reject, phone numbers, settings, passcode
5. Consultancy: handover passcode, students, approve, buy seats, top up
6. Owner: kill switch
7. What is NOT built: how far does it go, and would AI make it better
